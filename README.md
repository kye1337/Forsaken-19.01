# Forsaken-19.01
Fortnite game server version 19.01. This is my second-ever game server, so do not expect the code to be great. Development of this game server started in December 2025 and ended in February 2026.

This game server features decent implementation for phoebe (player AI). This is something that is extremely gatekept in the community, so I decided to open-source my old implementation for it.
